## 1. 화면 (하단 탭 5개)
`📅 일정(첫 화면) · 💬 채팅 · 🗣️ 말하기 · 📷 사진 · ℹ️ 정보` — 첫 접속 시 이름 선택(폰에 기억)

### F1. 💬 채팅 (가족 공용방 1개)
- GPT 여행 비서. 일정·가족·예약·메모·정보 탭 내용을 알고 대답
- 질문자 이름 표시, 4초마다 새 메시지 확인 → 다른 가족 질문·답도 보임
- **에이전트**: 일정 추가/수정/삭제, 메모 저장, 웹 검색(영업시간·날씨·교통)
- 빠른 질문 버튼: 오늘 일정 / 다음 일정 가는 법 / 근처 맛집 / 날씨 / 한식당
- **💬 카톡 공유**: 답변마다 버튼 → 폰 공유 시트(카톡 선택). 안 되면 **복사 + "카톡 열기"** 버튼

### F2. 📅 일정 (첫 화면)
- 첫 화면: 일자별 **큰 카드 4개**(날짜별 색, 핵심 일정 최대 4개, 예약✓) + 상단 안내(출발 전 D-day / 여행 중 "다음 일정" / 여행 후 사진 안내)
- 카드를 누르면 **일자별 하위 페이지**(`/day/날짜`): 타임라인, 다음 일정 빨간 강조, 이전·다음 날 이동
- 항목: 시간 · 한글/중국어 이름 · **중국어 아래 한글 발음**(누르면 음성, 새 항목은 자동 생성) · 메모 · 예약✓ · 🗺️ 지도 · ✏️ 수정
- **🍽️ 메뉴** (식당·한식당): 웹에서 메뉴를 찾아 대표 메뉴/기타 메뉴(한국어·중국어·발음·가격·설명) + 주문 팁 + 출처. 한 번 찾으면 저장, "다시 찾기" 가능. 메뉴를 누르면 "我要這個：○○" 점원용 화면 + 음성
- **장소를 누르면 → 말하기 탭(그 장소용 표현)**
- 날짜마다 **🍚 한식당 칸**: 직접 추가 / 🤖 AI 추천(채팅으로 이동해 자동 질문)

### F3. 🗣️ 말하기 (파파고 스타일)
- 카테고리: 장소별 · ⭐내 표현 · 기본 · 식당 · 택시 · 호텔 · 가게·음료 · 관광지 · 편의점·MRT · 공항 · 긴급
- 표현 누르면 → **중국어 큰 글씨 전체화면 + 대만 중국어 음성**(폰에 음성이 없으면 서버 음성)
- 장소에서 들어오면 "이 주소로 가 주세요(중국어 주소)" + 장소 맞춤 표현 + **🤖 표현 더 만들기**
- 직접 입력 번역 (한→중 / 중→한), ☆ 즐겨찾기, 저장

### F4. 📷 사진 (신규)
- 가족 누구나 **여러 장 한 번에 업로드**(사진·동영상), 작은 썸네일로 목록 → 데이터 절약
- 올린 사람별 필터, 누르면 크게 보기 / 다운로드 / 삭제
- **선택 → N장 저장**: 폰에서는 공유 시트로 "사진 앱에 저장", PC는 zip 다운로드
- 저장소: 로컬 개발 = `uploads/` 폴더, 배포 = Vercel Blob(비공개)

### F5. ℹ️ 정보
- 숙소, **📝 가족 메모**(AI도 참고), 한국이랑 다른 점, 영어 안 통할 때 요령
- **1일차 오후 A~D안 비교 + 고궁박물관 옵션 + 추천**, 3일차 동선 시간표

## 2. 확인된 이슈
- A안의 **국립역사박물관**(호텔 옆)과 **국립고궁박물관**(스린, 반나절)은 다른 곳 → 어느 쪽인지 결정 필요
- 고궁박물관은 일정상 **1일차 오후가 사실상 유일한 기회**
